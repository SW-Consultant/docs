Политика конфиденциальности

Версия документа: 2026. Разработчики: Класс Глеб Станиславович, Кондратенко Кирилл Витальевич.

Основная цель. Обеспечить прозрачность сбора, хранения и использования данных, обрабатываемых сервисом-ботом. Доступ к данным имеют исключительно разработчики. Документ доступен для скачивания всем посетителям.

1. Назначение сервиса и целевая аудитория

Данный ресурс предоставляется в форме независимого сервис-бота, созданного для информирования, консультирования и поддержки конечных пользователей. Сервис ориентирован на физических лиц, которые используют Telegram для получения рекомендаций, сведений о продуктах и управления подпиской на сервисные продукты.

В настоящем документе изложены правила обработки данных в отношении предоставления указанных услуг; технические детали реализации не являются предметом данного соглашения.

2. Категории обрабатываемых данных

Сервис обрабатывает следующие категории информации:

  • Telegram-идентификаторы и публичные имена пользователей;
  • пользовательские настройки и параметры профиля: язык, страна, тип пользователя, статус подписки, тарифный план;
  • медицинские и персональные данные, которые пользователь может указать: возраст, рост, вес, аллергии, состояние здоровья, прием лекарств, диетические предпочтения, уровень активности;
  • платежные метаданные: идентификаторы транзакций, email плательщика, статус платежа, сумма, товар, id webhooks, пользовательский идентификатор;
  • данные Google Sheets: содержимое таблиц, включая потенциально контактные данные и адреса электронной почты;
  • технические данные и логи, необходимые для поддержки работоспособности, диагностики и безопасности.

3. Цели обработки данных

Данные обрабатываются для следующих целей:

  • предоставления сервисных функций Telegram-бота;
  • управления подписками и активации сервисов;
  • персонализации ответов и качества консультаций;
  • обработки платежных уведомлений через Tribute;
  • очистки и подготовки данных Google Sheets;
  • обеспечения безопасности и контроля доступа.

4. Основания для обработки

Обработка данных происходит на основании:

  • согласия пользователя при использовании сервиса;
  • необходимости выполнения договора об оказании услуг;
  • законных интересов разработчиков в поддержании работоспособности и безопасности проекта.

5. Обработка платежных данных

Сервис получает платежные события исключительно через webhook Tribute. Проект обрабатывает только метаданные транзакции, необходимые для подтверждения подписки и статуса доступа.

Проект не хранит и не обрабатывает платежные реквизиты, номера банковских карт, CVV-коды, пароли или другие секретные данные, относящиеся к оплате. Ответственность за безопасность и конфиденциальность платежной информации несет Tribute.

Разработчики не несут ответственности за хранение, передачу или обработку платежных реквизитов, которые находятся вне зоны контроля данного проекта.

6. Хранение данных

Данные хранятся в базе данных и файлах логов, необходимых для работы сервиса. Логирование используется для диагностики и аудита.

Для доступа к Google Sheets используется сервисный аккаунт, представленный файлом keys.json, а доступ к API управляется через переменные окружения.

7. Передача данных третьим лицам

Данные не передаются сторонним организациям без явного согласия пользователя, за исключением случаев, предусмотренных законодательством.

Передача данных партнёрам возможна только если это необходимо для обработки платежа или выполнения обязательств по подписке.

8. Независимость проекта

Проект является независимым от компании Siberian Wellness сервисом. Siberian Wellness не управляет проектом, не контролирует работу сервиса и не имеет права на сервис.

При использовании информации о товарах и продуктах проекта применяется только общедоступная информация о продукции Siberian Wellness. Проект не является официальным представителем или партнёром Siberian Wellness.

9. Защита и доступ

Доступ к данным имеют только разработчики проекта. Они обязуются:

  • не раскрывать данные без разрешения;
  • использовать защищённые соединения и защищённое хранение ключей;
  • своевременно обновлять защитные меры.

10. Права пользователя

Пользователь имеет право:

  • запрашивать информацию о том, какие данные о нём хранятся;
  • требовать корректировку неточных данных;
  • запросить удаление данных в пределах, допускаемых работоспособностью сервиса.

Разработчики оставляют за собой право вносить изменения в документ. Важные обновления публикуются открыто в рамках проекта.
